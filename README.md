## 問題回答

1. **為什麼文字人數 `"4"` 要先轉成數字？**
   因為 `"4"` 在 Python 中是字串（`str`），而 `4` 才是整數（`int`）。本題需要使用人數作為除數來計算每人分攤費用，Python 無法直接將數值除以字串（若當成文字相加 `"4" + "1"` 也會變成 `"41"` 而非 `5`），因此必須先透過 `int(people)` 轉換成整數型別才能進行數學除法運算。

2. **如果先扣折價券，再計算服務費，第一組總額為何會變成 1,210 元？**
   若先扣除 100 元折價券，餐費計算基準會變成 `1,200 - 100 = 1,100` 元；以此計算 10% 服務費為 `1,100 × 0.10 = 110` 元，應付總額就會變成 `1,100 + 110 = 1,210` 元（每人 302.50 元）。由於題目規定必須按原始餐費（1,200 元）計算服務費（120 元），先折價會少算 `100 × 0.10 = 10` 元服務費，因此必須先算服務費再扣折價券，總額才是正確的 1,220 元。
